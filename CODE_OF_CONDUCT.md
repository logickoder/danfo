# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

The short version: be respectful, assume good faith, keep criticism about the code, and do not
harass anyone. Trolling, insults, doxxing and sustained disruption get you removed from the
project's spaces.

Report unacceptable behavior privately to the maintainer via GitHub
([@logickoder](https://github.com/logickoder)). Reports are handled confidentially.

Maintainers who fail to uphold this standard hold themselves to the same consequences.
